Entry for the [make.fun](https://make.fun) competition **The Meeting That Should Have Been One Line** (`u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c`).

One sentence, 17 words, 95 characters: the action item from this meeting is to stop having this meeting — and consider it already done. It kills this meeting and every follow-up in a single deadpan line.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `/output/entry.txt`, then validates it against the competition gate before writing: 1–200 characters, non-whitespace, a single line, exact expected length and word count, no leading/trailing whitespace, no double spaces. Requires Node 22.18 or later.
